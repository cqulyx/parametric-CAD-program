# parametric-CAD-program

We propose a constraint-guided framework that automatically converts engineering drawings into editable parametric CAD models. By integrating multimodal perception, CAD-oriented semantic guidance, and iterative program refinement, our approach minimizes manual reconstruction while preserving design parameters and modeling operations for flexible editing and reuse.

# Getting started

Installation.

```bash
poetry install
```

Run script. A STEP file ("output.step") will be generated.


```bash
streamlit run app.py
```
The demonstration video is publicly available at：https://www.youtube.com/watch?v=OuwM0NrdDh0.
